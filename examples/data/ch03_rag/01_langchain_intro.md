# LangChain 핵심 개념 노트

## LangChain이란

LangChain은 언어 모델을 활용하는 애플리케이션을 만들 때 반복적으로 필요한 구성 요소를 표준화된 인터페이스로 제공하는 프레임워크입니다. 모델 호출, 프롬프트 구성, 출력 파싱, 여러 단계를 연결하는 방법까지 하나의 일관된 방식으로 다룰 수 있게 해 줍니다.

## Runnable 인터페이스

LangChain의 거의 모든 구성 요소는 Runnable이라는 공통 인터페이스를 따릅니다. Runnable은 크게 세 가지 실행 방법을 제공합니다. invoke는 입력 하나를 받아 결과 하나를 반환하는 가장 기본적인 호출 방식입니다. batch는 여러 입력을 한 번에 넘겨 각각의 결과를 리스트로 돌려받는 방식으로, 여러 건을 처리할 때 호출 오버헤드를 줄여 줍니다. stream은 결과가 완성되기를 기다리지 않고, 생성되는 대로 조각 단위로 즉시 받는 방식입니다. 이 세 방법은 프롬프트 템플릿이든 모델이든 파서든 동일하게 적용됩니다.

## 파이프 연산자로 단계 연결하기

여러 Runnable을 순서대로 실행해야 할 때는 파이프 연산자를 사용해 이어 붙입니다. 파이프 연산자는 앞선 구성 요소의 출력을 다음 구성 요소의 입력으로 그대로 전달하는 역할을 합니다. 예를 들어 프롬프트 템플릿, 모델, 출력 파서를 순서대로 연결하면, 사용자가 넘긴 값이 프롬프트 문자열로 채워지고, 그 문자열이 모델에 전달되어 응답을 만들고, 그 응답이 파서를 거쳐 최종 형태로 정리되는 하나의 흐름이 만들어집니다. 이렇게 연결된 결과 역시 Runnable이므로 다시 다른 구성 요소와 연결할 수 있습니다.

## 프롬프트 템플릿과 출력 파서

프롬프트 템플릿은 고정된 지시문 안에 변하는 값만 자리표시자로 남겨 두고, 실행 시점에 실제 값을 채워 넣는 역할을 합니다. 같은 지시문 구조를 여러 입력에 반복해서 재사용할 수 있게 해 줍니다. 출력 파서는 모델이 돌려준 응답을 애플리케이션이 다루기 좋은 형태로 바꾸는 역할을 합니다. 가장 단순한 형태는 응답에서 텍스트만 뽑아내는 파서이고, 더 나아가면 정해진 구조를 갖춘 값으로 변환하는 파서도 있습니다.

## 도구를 요청하는 모델

일부 상황에서는 모델이 스스로 외부 기능을 실행하지 않고, 대신 어떤 기능을 어떤 값으로 실행해 달라는 요청만 응답에 담아 돌려줍니다. 실제로 그 기능을 실행하는 것은 모델을 호출한 코드의 몫입니다. 이렇게 요청과 실행을 분리해 두면, 모델은 무엇을 해야 할지 판단하는 역할에 집중하고, 실행 결과의 신뢰성과 안전성은 호출하는 쪽에서 책임지고 관리할 수 있습니다.
