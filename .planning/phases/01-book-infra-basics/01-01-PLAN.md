**`examples/shared/config.py`** (anchor comments are part of the contract, because chapters include these regions):
```python
"""예제 전체가 공유하는 LLM 설정. 모든 예제는 여기서만 채팅 모델을 만든다."""
import os
from dataclasses import dataclass, field
from pathlib import Path

from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

EXAMPLES_DIR = Path(__file__).resolve().parent.parent
ENV_PATH = EXAMPLES_DIR / ".env"

# ANCHOR: settings
@dataclass(frozen=True)
class Settings:
    base_url: str
    model: str
    api_key: str | None = field(default=None, repr=False)  # repr에 키가 찍히지 않게

def load_settings() -> Settings:
    load_dotenv(ENV_PATH, override=False)  # 이미 설정된 환경변수가 우선
    base_url = os.environ.get("LLM_BASE_URL", "").strip()
    model = os.environ.get("LLM_MODEL", "").strip()
    if not base_url or not model:
        raise RuntimeError(
            "LLM_BASE_URL / LLM_MODEL이 설정되지 않았습니다. "
            "examples/.env.example을 examples/.env로 복사한 뒤 값을 채우세요."
        )
    return Settings(base_url=base_url, model=model,
                    api_key=os.environ.get("LLM_API_KEY", "").strip() or None)
# ANCHOR_END: settings

# ANCHOR: chat_model
def get_chat_model(**overrides) -> ChatOpenAI:
    s = load_settings()
    params = dict(
        base_url=s.base_url,
        model=s.model,
        api_key=s.api_key or "not-needed",  # 인증 없는 로컬 서버는 아무 값이나 허용
        temperature=0,     # 캡처 재현성을 위해 기본 0
        timeout=120,       # 콜드 스타트(첫 요청 수십 초) 대비
        max_retries=1,
    )
    params.update(overrides)
    return ChatOpenAI(**params)
# ANCHOR_END: chat_model

# ANCHOR: structured
def get_structured_model(schema, **overrides):
    # 로컬 서버는 기본값(json_schema)에서 500 에러 → function_calling + strict=False로 통일
    return get_chat_model(**overrides).with_structured_output(
        schema, method="function_calling", strict=False
    )
# ANCHOR_END: structured
```
Comments may be polished, but keep the function names, signatures, defaults, and the three anchor names. Anchor comment lines must sit on their own lines, because mdBook shows them verbatim in whole-file includes. Chapters therefore include config.py only by anchor.

`scripts/masking.py` (stdlib only):
- `SECRET_ENV_VARS = ("LLM_API_KEY", "LITELLM_API_KEY", "OPENAI_API_KEY", "LANGSMITH_API_KEY")`
- `KEY_MASK = "***MASKED_API_KEY***"`, `TOKEN_MASK = "***MASKED***"`, `HOME_MASK = "~"`
- `collect_secrets(extra=()) -> list[str]`: gathers non-empty stripped values of `SECRET_ENV_VARS` from `os.environ` plus `extra`, deduplicated and sorted longest first. Empty or None values are skipped.
- `mask_text(text, secrets, home=None) -> str`, applied in this order:
  1. Literal replacement of each secret value with `KEY_MASK`, longest first.
  2. Regex `\bsk-[A-Za-z0-9_\-]{8,}` becomes `sk-***MASKED***`.
  3. Regex `(?i)\b(Bearer\s+)[A-Za-z0-9._~+/\-]{8,}=*` becomes `\1***MASKED***`.
  4. The literal home path (`home` or `str(Path.home())`) becomes `~`, using `re.escape`.
  5. Generic `/Users/[^/\s"'<>]+` and `/home/[^/\s"'<>]+` become `~`.
  Masking the literal value is mandatory whatever its length. Never skip short secrets.
- `find_leaks(text, secrets, home=None) -> list[str]` returns leak **kinds** only (`"literal-secret"`, `"sk-token"`, `"bearer-token"`, `"home-path"`, `"users-path"`) and never the matched value. Before the literal-secret check, remove the mask tokens from the text, so a secret that happens to be a substring of `***MASKED_API_KEY***` cannot cause a permanent false positive.

Test cases (minimum):
- a short fake secret with no prefix (e.g. `"q7Zx2"`) is masked everywhere, including twice in one line
- longest-first ordering, where one secret is a prefix of another
- `sk-abcdefghijklmnop` is masked
- `Authorization: Bearer abcdefgh12345678` is masked
- `home="/Users/alice"` turns `/Users/alice/projs/x.py` into `~/projs/x.py`
- `/Users/bob/tmp` is masked generically
- Korean text and normal prose (`"스크럼 task-list"`) are unchanged
- `find_leaks` is non-empty before masking and `[]` after masking for all of the above
- `find_leaks` output never contains the secret string
- `collect_secrets` reads env via `monkeypatch.setenv` and ignores empty values

`scripts/check_leaks.py` CLI: `check_leaks.py [--secrets-only] PATH [PATH ...]`
- A PATH can be a file, a directory (walked recursively, skipping `.git`, `.venv`, `__pycache__`, `node_modules`, and files named exactly `.env`), or `-` for stdin.
- Read bytes and decode UTF-8 with `errors="replace"`. Skip files larger than 20 MB.
- Secrets come from `collect_secrets()` after trying `from shared.config import load_settings; load_settings()`, which loads examples/.env. Wrap that import in try/except so the scanner still works on env only.
- Default mode reports every `find_leaks` kind. `--secrets-only` reports only `literal-secret`, for tracked planning docs and git history that legitimately mention `/Users/...` or contain test fixtures.
- Print `relative/path:LINE: kind`, one per finding, with no matched text. The path is relative to cwd and passed through `mask_text`. Print `CLEAN` and exit 0 when nothing is found, otherwise exit 1.
- Import masking via the script's own directory (`sys.path[0]` is `scripts/` when run as `python scripts/check_leaks.py`).

Commit the three files.
