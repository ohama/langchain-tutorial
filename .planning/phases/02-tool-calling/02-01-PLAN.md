Imports: `json`, `HumanMessage, ToolMessage` from `langchain_core.messages`, `get_chat_model`, `ALL_TOOLS, lookup_stock` from `shared.tools`. Module-level definitions:

- `fmt_call(tc)` returns `f"{tc['name']}({json.dumps(tc['args'], ensure_ascii=False)})"`
- `run_tool_call(tc) -> ToolMessage`:
  - Unknown name: return `ToolMessage(content=f"알 수 없는 도구: {tc['name']}", tool_call_id=tc["id"], name=tc["name"], status="error")`.
  - Otherwise, inside `try`, `return tool.invoke(tc)`. Pass the FULL tool_call dict, which makes langchain build the ToolMessage; add a comment saying so.
  - `except Exception as e:` return `ToolMessage(content=f"도구 실행 오류: {type(e).__name__}: {e}", tool_call_id=tc["id"], name=tc["name"], status="error")`.
- `run_loop(model_with_tools, question)`:
  1. Set `messages = [HumanMessage(question)]` and print `질문: ...`.
  2. `for step in range(1, MAX_ITERS + 1):`
     - `ai_msg = model_with_tools.invoke(messages)`, then append it.
     - If `not ai_msg.tool_calls`: print `[{step}] 모델 응답: 도구 호출 없음 → 최종 답` and `최종 답: {ai_msg.content}`, then `break`.
     - Otherwise print `[{step}] 모델 응답: tool_calls {n}개`. If `ai_msg.content` is non-empty, also print `    content: ...`.
     - For each tc: `tm = run_tool_call(tc)`, append it, and print `    → {fmt_call(tc)} = {tm.content}`.
  3. The `else:` branch of the for loop prints `최대 반복({MAX_ITERS}회) 도달 — 최종 답을 얻지 못함`.
  4. After the loop, print `메시지 흐름: ` + `" → ".join(type(m).__name__ for m in messages)` and return messages.
