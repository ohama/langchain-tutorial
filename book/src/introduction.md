# 소개

## 이 책은 무엇인가

이 책은 LangChain 기초에서 시작해 LangGraph로 만드는 에이전트, 그리고 최종적으로 샌드박스에서 동작하는 코딩 에이전트까지 이어지는 개인 학습 기록이다. 전 과정을 공개했으므로 누구나 순서대로 따라 하며 같은 결과를 재현해 볼 수 있다.

## 이 책의 약속

이 책에 실린 모든 코드 블록은 저장소 안에 실제로 존재하는 파일이며, 실제로 실행된 것이다. 모든 출력은 저자의 로컬 LLM(LiteLLM 프록시, `flashnext` 별칭)을 호출해 캡처한 실제 결과다. LLM 출력은 본질적으로 비결정적이므로, `temperature=0`으로 설정하더라도 독자가 직접 실행한 결과가 이 책에 실린 출력과 글자 단위로 완전히 같지 않을 수 있다.

## 챕터 구성

모든 챕터는 같은 순서를 따른다.

1. **개념** — 왜 이 기능이 필요한가
2. **최소 코드** — 개념을 보여주는 가장 짧은 예제
3. **실제 출력** — 그 코드를 실행해 캡처한 결과
4. **요점 정리** — 챕터에서 기억해야 할 핵심

## 저장소 구조

- `book/` — 이 책의 원고 (mdBook 소스)
- `examples/` — 실행 가능한 예제 코드 (uv 프로젝트)
- `outputs/` — 예제를 실행해 캡처한 실제 결과
- `scripts/` — 예제를 실행하고 결과를 캡처·검사하는 도구

## 준비물

- Python 3.14 이상과 [uv](https://docs.astral.sh/uv/)
- OpenAI 호환 LLM 엔드포인트 (Chat Completions API 호환)

이 책은 기본값으로 로컬 LiteLLM 프록시를 사용하지만, `.env` 파일만 수정하면 다른 OpenAI 호환 엔드포인트로 바꿀 수 있다. 구체적인 설정 방법은 [1장](ch01_basics/01_chat_model.md)에서 다룬다. 로컬 LLM을 새로 설치하는 방법은 부록에서 다룰 예정이다.
